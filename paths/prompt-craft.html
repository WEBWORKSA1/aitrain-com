Prompt Craft Line

A practical method for writing prompts that work the first time: role, context, task, constraints and format, then iteration and reusable templates.

Beginner → Intermediate8–10 hours7 stationsFree

Who it's for: People who already use an AI assistant and want consistent, high-quality results instead of lucky ones.

What you'll be able to do

  • Use a repeatable five-part prompt structure
  • Turn a messy request into a reusable template
  • Use examples (few-shot) to lock in tone and format
  • Break large tasks into chained prompts

The route

  1. Station 1: The five-part prompt

    Role, context, task, constraints and output format — why each part removes a specific kind of guesswork.

  2. Station 2: Giving context that counts

    How much background to include, what to leave out, and how to paste source material so the model uses it.

  3. Station 3: Examples beat adjectives

    Show one or two examples of the output you want instead of describing it; the single biggest quality jump for most people.

  4. Station 4: Structured outputs

    Ask for tables, checklists, JSON or headings so results drop straight into your documents and tools.

  5. Station 5: Iterate like an editor

    Targeted follow-up prompts that fix one thing at a time instead of starting over.

  6. Station 6: Prompt chains

    Split research, outline, draft and review into separate steps for longer or higher-stakes work.

  7. Station 7: Building a team prompt library

    Name, version and share prompts so a whole team benefits from the best ones.
